# Complex Number Calculator (C++)

A beginner-friendly console project demonstrating operator overloading in C++.

## Features
- Reads two complex numbers from the user.
- Adds the numbers using the overloaded `+` operator.
- Subtracts the numbers using the overloaded `-` operator.
- Displays a complex number using the overloaded `<<` operator.
- Uses a class, private data members, and a constructor.

## Files
- `main.cpp` — complete C++ source code.
- `Project-Report.md` — project report.
- `Sample-Output.txt` — example program output.

## Compile and run
Using g++:

```bash
g++ -std=c++11 main.cpp -o calculator
./calculator
```

On Windows, run `calculator.exe` after compiling.
